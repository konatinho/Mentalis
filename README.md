---

## 📌 Sobre o projeto

O **Mentalis** é um site desenvolvido como projeto escolar da disciplina de Front-End, proposto pelo professor como atividade prática para a turma.

O objetivo foi aplicar conhecimentos de **HTML, CSS e JavaScript** na criação de um site com conteúdo informativo sobre saúde mental e bem-estar.

## 🎯 Objetivo

Este projeto teve como objetivo praticar o desenvolvimento de interfaces web, incluindo:

- Estruturação de páginas com HTML  
- Estilização com CSS  
- Organização de conteúdo  
- Interatividade com JavaScript  

---

## 🚀 Funcionalidades

- 📚 Conteúdos de psicoeducação  
- 🧠 Informações sobre saúde mental e emoções  
- 🌐 Navegação entre páginas  
- 🎨 Interface simples e responsiva
